# Phase 25 Real Ephemeris Fixtures

`iss-zarya.tle` is a real GP/TLE element set for ISS (ZARYA), NORAD 25544, retrieved from CelesTrak's public GP endpoint during Phase 25 development.

Source endpoint:
https://celestrak.org/NORAD/elements/gp.php?CATNR=25544&FORMAT=TLE

The fixture is a point-in-time test input. It must not be treated as a permanently current orbit. Refresh it from the source when running operational experiments.
