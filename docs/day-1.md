# Day 1 — Foundation Baseline

Implemented:

- Typed domain models for users and network nodes.
- Geographic coordinate validation.
- Friis free-space path loss.
- Thermal-noise power with receiver noise figure.
- Received-power and SINR calculations.
- Deterministic link simulation.
- Structured telemetry event helper.
- Configuration file.
- Automated physics/model tests.

Intentionally not implemented yet:

- Satellite orbital propagation.
- Horizon/line-of-sight geometry.
- Doppler.
- Fading/multipath models.
- Traffic generator.
- Handover policy.
- Digital Twin synchronization.
- AI prediction.
- Autonomous orchestration.

These stay out of the first baseline until the physical/network foundation is validated.
